# Meizu MX6 (m95) vendor blobs

Proprietary files for the Meizu MX6 (m95, MT6797), LineageOS 20.0.

Used by [android_device_meizu_m95](https://github.com/nomorecoolnicknames/android_device_meizu_m95) (`lineage-20.0`).

Source: stock Flyme 8.0.5.0A (Android 7.1.1, NMF26O). Files ending in `.orig` are unmodified stock copies kept by the
device tree's blob patch tools; they are not installed.

The files are property of Meizu and MediaTek and keep their original terms.
